# NCC 2025 — structure

Three volumes.

| Volume | Covers |
|---|---|
| **One** | Class 2–9 buildings — the Building Code of Australia. **Retail fitout lives here** (Class 6). |
| **Two** | Class 1 and 10 — houses, sheds, garages. Plus the Housing Provisions. |
| **Three** | Plumbing and drainage — the Plumbing Code of Australia (PCA). |

## Volume One sections

| Section | Subject | Bites on a fitout? |
|---|---|---|
| A | Governing requirements — how the Code is applied, building classification, compliance pathways | Always. Classification and the compliance pathway are decided here. |
| B | Structure | Only where the fitout loads or penetrates structure |
| C | Fire resistance | Fire-rated tenancy separation, penetrations, fire hazard properties of linings |
| D | Access and egress | **Heavily.** Exit travel distances, door swings, path of travel, accessibility, wayfinding |
| E | Services and equipment | **Heavily.** Sprinklers, detection, hydrants, exit and directional signage, lifts |
| F | Health and amenity | **Heavily.** Sanitary facilities, ventilation, waterproofing, light, condensation |
| G | Ancillary provisions | Occasionally — construction sites, atriums |
| H | Special use buildings | Rarely for retail |
| J | Energy efficiency | **Heavily.** Lighting power and control, HVAC, on-site renewables |

Schedules 1–11 carry definitions, the list of referenced documents (Schedule 2 — this is where the
AS/NZS references live), and the state and territory variations. **Always check the state schedule**:
NSW, VIC and QLD each vary the base provisions, and a clause that reads one way nationally may be
amended or deleted in the jurisdiction the job sits in.

## Clause numbering

NCC 2019 renumbered to the current scheme, so older documents cite the old form and it is easy to
mismatch a citation across editions.

```
J7D3       Section J, Part 7, Deemed-to-Satisfy provision 3
D1P10      Section D, Part 1, Performance requirement 10
C1V3       Section C, Part 1, Verification method 3
S25C2      Specification 25, clause 2
```

The letter before the number is the provision type:

- **P** — Performance Requirement. The thing that must actually be achieved.
- **D** — Deemed-to-Satisfy. One prescriptive way of achieving it.
- **V** — Verification Method. A test that demonstrates the Performance Requirement is met.
- **S** — Specification. Detailed technical requirements called up by a clause.

## Compliance pathways

Every solution is one of:

1. **Deemed-to-Satisfy** — follow the DTS provisions. Most fitouts.
2. **Performance Solution** — demonstrate the Performance Requirement is met another way. Requires a
   report from a suitably qualified person, and the assessment method must be stated.
3. A combination of both.

**A Performance Solution is a PM issue, not just a design issue.** It has to be documented,
assessed, accepted by the certifier, and it travels into the fire safety schedule and the handover
documentation. An undocumented Performance Solution found late is an occupancy risk, not a drafting
problem. When a drawing set relies on one, that belongs on the clarifications register.
