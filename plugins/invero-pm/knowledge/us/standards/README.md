# Referenced standards

The I-Codes call up hundreds of referenced standards — the IBC lists them in its referenced-standards
chapter — published by NFPA, ASTM International, ANSI-accredited bodies, ASHRAE, UL, ACI, AISC and
others. **They are copyrighted.** Several publishers offer free read-only access online; none of
that is a licence to reproduce. This branch therefore holds **pointers and paraphrase only**, and
`kb-lint.py` flags any long quoted run here as suspected reproduced text.

`index.json` lists the standards a commercial fitout most often meets: number, title, what it
governs, the code hook that calls it up, and the **PM trigger** that should send you to it.

**Which edition applies is not in this index.** The edition is the one the adopted code references
(see `../codes/README.md`), which may not be the publisher's latest. Record the edition in the
finding, from the adopted code's referenced-standards list.

**Provisional.** The paraphrase is for triage — deciding whether a standard applies and whether
something needs checking. What would verify an entry: a person checks it against the standard
itself. **It is not a substitute for the standard when a compliance position is being taken** — open
the licensed or read-only copy.
